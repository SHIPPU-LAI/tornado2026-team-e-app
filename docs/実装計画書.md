```bash
# 2 認証

  -d '{"email":"a@example.com","password":"pw12345678","role":"artisan","display_name":"テスト工房"}'

  -H 'content-type: application/json' \

#   カードを作った直後に
curl -s 'localhost:8787/api/search?q=<作ったカードに関係する言葉>'
```

## 2. AIエージェントへの出し方

**1ステップ＝1タスク。並列にしない。**
読めるのは自分ひとりなので、生成の速さではなく**読む速さが上限**になります。

各タスクを出す前に、**確認コマンドを先に渡します。**
「これが通ったら完成」を先に決めておかないと、毎回どこまでやったか揺れます。

**毎回釘を刺すこと**

```
・cards テーブルに列を足さない（card_geo / card_i18n / card_images に外出しする）
・app.use("*") を使わない。自分の接頭辞で限定する
・静的パスを :id より先に書く
・APIキーをブラウザに渡さない
```

**1ステップ終わるごとに必ずコミット。**読めていないコードが増えるので、
戻れる地点を細かく作るのが唯一の保険です。

## 4. 9/4 にやること

**新しい機能を足さない日**にします。

```
午前  フロントエンドとのすり合わせ
      ・レスポンスの形が画面に合っているか
      ・足りない項目が無いか
      ・CORSとCookieがフロントのオリジンから通るか  ← 詰まりやすい
午後  通しの手触り確認、ダミーデータの追加、デプロイ
      発表で見せる流れを実際に3回通す
```

**Cookie の SameSite は要注意。**フロントが別オリジンだと `SameSite=Lax` では送られません。
9/4 の午前にここを必ず確認します。**当日に気づくと詰みます。**
