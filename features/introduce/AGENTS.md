## この機能が担うもの

**カード作成機能を含みます。これがプロダクトの中核です。**

```
職人側     カードの作成・修正（伝統名・ふりがな・職人名・場所・説明文・タグ・画像）
           説明文のAI3文チェック／言い換え提案
           ふりがなの自動生成
           伝統名の予測変換（レーベンシュタイン距離。「あいまい検索」と呼ばれている）
ユーザー側 マッチング（伝統名単位で1枚に集約）／記事一覧／記事詳細／いいね／評価
```

## 持つパス

```
GET  /user                      マッチング画面
GET  /user/tradition/:name      記事一覧
GET  /user/card/:id             記事詳細
GET  /artisan                   職人向け登録・修正画面
     /api/introduce/user/*      ユーザー側API
     /api/introduce/artisan/*   職人側API
```

## この機能に固有の注意

- **「あいまい検索」という語が2箇所で別の意味に使われています。**
  ここは登録時の予測変換（文字列の近さ）、検索機能は意味検索（ベクトル）。混同しないこと
- **D1 のバインディング名が `teame_taka_introduce` になっています。**
  検索機能は `DB` を使っており、統合時に衝突します。統一が決まるまで勝手に変えないでください
- **Google Maps は使わない方針です。**仕様書に「Google Maps embed」の記載がありますが、
  方針と整合するか未確認です。地図を触るときは人間に確認してください
